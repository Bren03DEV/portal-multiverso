O **VRZ NEWS** é o portal oficial de notícias e lançamentos do coletivo independente **VRZ RECORDS**. O projeto foi desenvolvido com uma estética moderna baseada no estilo *Cyberpunk*, utilizando tons de roxo neon, sombras projetadas (glow) e fundo escuro absoluto para destacar o conteúdo artístico.

---

## 🎨 Identidade Visual
O design do site foi pensado para refletir a energia do cenário musical independente:
* **Cores Principais:** Preto Absoluto (`#0a0a0a`) e Roxo Neon (`#a259ff`).
* **Tipografia:** `Orbitron` para títulos (estilo futurista) e `Poppins` para leitura.
* **Efeitos:** Bordas neon, animações de pulsação e botões interativos.

## 📂 Estrutura do Projeto

O projeto está organizado para facilitar a manutenção e escalabilidade:

```text
