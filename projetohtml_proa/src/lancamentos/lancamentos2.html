Policromia

Fabbin começou esse ano com o lançamento de "Policromia", este projeto mistura House com Funk + Pluggnb trazendo uma nova dimensão para o seu repertório. "Policromia" apresenta uma mistura de estilos musicais, com letras profundas e batidas envolventes, refletindo todo o potencial de Fabbin. O lançamento tem sido uma surpresa para os fãs porém muito bem recebida pelos mesmos.
